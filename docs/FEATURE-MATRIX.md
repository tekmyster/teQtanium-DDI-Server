# DDI implementation and delivery status

teQtanium is a developing alpha DDI fork. GPL permissions and separately licensable commercial offerings are described in [license policy](../LICENSE.md). Feature names do not establish proprietary licensing, delivery, vendor parity, detection accuracy or enterprise availability. See [dated deployment status](DEPLOYMENT-STATUS.md) for acceptance and deployment; source availability is a separate publication outcome.

| Capability | Implemented source behavior | Remaining requirements or qualification |
| --- | --- | --- |
| DNS foundation | Upstream authoritative/recursive DNS, DNSSEC and encrypted transports retained | Deployment-specific transport, policy, upgrade, compatibility and throughput matrix |
| Multi-owner IPv4 DHCP | New plans use stable sorted-owner `interleaved-v1` eligible ranks; legacy plans retain their algorithm; durable offers/ACK leases, exclusions and deterministic reservations | Live membership/range/exclusion/reservation migration and broader crash/platform qualification |
| DHCP replication | Sequenced snapshots over direct HTTPS among enrolled peers; local authority survives failed sync | Latest parser repair locally accepted, undeployed; live causal diagnosis inferred; no claim that production warning is resolved |
| Owner isolation and overflow | Unchanged exclusive sequences; own available capacity exhausted before durable donor grants; prior grants remain usable during isolation | Grant return/reclamation, unknown-outcome capacity recovery and donor-loss recovery |
| Unused-owner recovery | Original-journal command and receiver import divide only unused eligible capacity; protected leases/offers/quarantine/reservations retained | VMware controller safety quarantine locally accepted only; usable recovery incomplete and automation Disabled; no enablement implied |
| Lease-preserving failover | Historical bounded Hyper-V fenced takeover/promotion and power-loss retests | Current production HA not accepted; automatic rejoin/failback, redundant controllers and provider/failure/partition qualification remain |
| Three or more nodes | Bounded three-server replication/partition fixtures; enrolled peers exchange snapshots | Safe three/five-voter membership consensus, learners, regional faults and scale qualification remain targets |
| IPv6 DDI | IPv6 DNS, IPAM and indicator matching | DHCPv6 service, synchronized allocation and recovery unimplemented |
| IPAM | Views, containers, IPv4/IPv6 intent, metadata, utilization, revisioned writes, source-labelled configured inventory and expiring lease observations; reviewed local IPv4 provisioning; bounded manual TCP/SNMP/Azure NIC observations | Production provisioning/discovery activation, other collectors, prefix allocation, scoped delegation/workflow and indexed enterprise storage |
| NetBox | DDI-owned publication, scheduled read-only reviews, individually selected managed deletion and missing-only reverse intent, explicit existing site/VLAN/tenant/device/interface mappings; [bounded contract](NETBOX-RECONCILIATION.md) | Independent local acceptance and live endpoint qualification; unattended publication, remote authority, DCIM creation and relationship unlinking |
| Threat inputs | Local rules, bounded asynchronous MISP and typed EDL input caches; unsupported/URL evidence stays distinct | Monitor input activation does not prove blocking or accuracy; API-only typed-feed scheduling/source-quality and exact QNAME RPZ fragment candidate are documented in THREAT-FEED-MANAGEMENT.md; independent acceptance pending |
| EDL output | Private authenticated typed exports of explicitly selected eligible indicators | Source/list selection, redistribution permission and consumer subscription/expiry acceptance; input activation is not output publication |
| Shared security evidence | Expiring DNS/DHCP context, bounded events, IPAM findings, timeline search/dispositions and policy rollback | Historical backfill, per-node signed evidence, finer roles, immutable external audit, long retention and response workflows |
| Behavioral analysis | Explainable five-minute/hour heuristic findings; [API-only local advisory model mechanics](PREDICTIVE-MODELS.md), frozen benign training baselines, provenance/time context and version/fallback lifecycle | Independent mechanical acceptance; authorized representative datasets, label/partition review and empirical qualification remain open; synthetic tests establish mechanics only |
| Optional LLM | Advisory on-demand explanations, constrained connector, process-local usage/outcome/latency/capacity dashboard, no policy tools | Current operation scoped accepted only; real-event/privacy/loaded-runtime/node-source/DHCP packet gates and multi-event evaluation remain |
| Integration health | Cache state/provenance/expiry separated from local refresh attempt/success/completeness | Local source/build accepted and undeployed; active cache is not current provider connectivity or enforcement proof |
| Syslog | Native UDP/TCP/TLS, validated collector trust, bounded asynchronous disk replay and health, per-node API settings, optional DNS query forwarding; [delivery contract](SYSLOG.md) | Independent candidate review, live Wazuh/relay compatibility and deployment throughput; queued/persisted/socket-write are distinct and no application receipt is implemented |
| Backup/migration | Selective native backups; API scheduled AES-256-GCM portable snapshots, current-session key delegation, authenticated preview, disabled scopes, retained identity, authority-free restart rollback and durable lost-reply receipts; local tests pending independent acceptance | Console controls, persistent key-store integration, coordinated snapshots, genuine online replacement/current-authority cutover, host power-loss and production qualification; copied leases convey no authority |
| Packaging | Alpha scripts/formats, unsigned Windows setup and [private versioned portable delivery](PRIVATE-DELIVERY.md) with full manifests, in-place data preservation and interrupted cutover discovery | Independent bounded package/native-platform qualification required; legitimate trusted signing unavailable in inspected references, public binaries held, production static-overlay integration/service-manager/full disaster recovery remain gates |
| Product UX | Responsive console/disclosures, structured evidence and shared UX contract | Continue workflow-specific UI/accessibility checks; historical screenshots are not every current state |

Use focused checks appropriate to the change. The broad `scripts/test-ddi.ps1` suite includes security/integration scenarios; it was not run for this documentation item. Existing test results retain their original bounded scope and do not establish production throughput, all management paths, detection accuracy or regional failover.
